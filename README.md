# SUAS Saúde / Saúde +Fácil

Ecossistema integrado de tecnologia voltado para a unificação de dados entre a saúde pública e a assistência social.

## Módulos do Sistema
* **Regulação Inteligente:** Gestão e acompanhamento de óculos, próteses e aparelhos auditivos.
* **Triagem Clínica:** Suporte ao Protocolo de Manchester para priorização de urgência.
* **Interoperabilidade:** Arquitetura flexível orientada à integração de fluxos socioassistenciais e de saúde.
